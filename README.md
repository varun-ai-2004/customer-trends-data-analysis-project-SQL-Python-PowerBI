# customer-trends-data-analysis-project-SQL-Python-PowerBI# Customer Trends Data Analysis | SQL, Python & Power BI

## Project Overview
This project analyzes customer shopping behavior to identify trends in purchasing patterns, customer spending, product performance, discounts, subscriptions, and revenue. Using SQL, Python, and Power BI, the project transforms raw data into meaningful business insights to support data-driven decision-making.

## Tools & Technologies
- **SQL** – Data analysis, aggregations, CTEs, subqueries, window functions and business queries.
- **Python** – Data analysis and exploration using Jupyter Notebook.
- **Power BI** – Interactive dashboards and data visualization.

## Business Questions
The project explores the following business questions:

1. What is the revenue distribution across genders?
2. Do customers who use discounts spend more than the average customer?
3. Which products have the highest average review ratings?
4. How does spending vary between Standard and Express shipping?
5. How do subscribers compare with non-subscribers in spending and revenue?
6. Which products have the highest discount rates?
7. How can customers be segmented into New, Returning and Loyal customers?
8. What are the top 3 products in each category?
9. How do repeat purchases relate to subscription status?
10. Which age groups contribute the most revenue?

## Project Files
- `mydataanaystproject.sql` – SQL queries for business analysis.
- `data_analyst_project.ipynb` – Python analysis notebook.
- `customer_behavior_dashboard.pbix` – Power BI dashboard.

This project demonstrates the use of SQL, Python, and Power BI to analyze customer behaviour, identify business trends and derive actionable insights related to customer engagement, purchasing patterns and revenue performance.
